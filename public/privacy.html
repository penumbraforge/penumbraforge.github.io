Privacy Policy

Last updated: August 29, 2026

Overview

Penumbra Forge LLC ("Penumbra Forge") is an independent software company building developer, AI, and security tools. Some routes are browser-local and others use workers, third-party services, or endpoints you configure; this policy describes those differences. It covers penumbraforge.com and the services we operate.

How Data Moves

Many tools run entirely in the browser, but not every feature is offline. Each tool page labels its route as browser, edge, network, or selectable AI and includes a short disclosure. Do not assume that every Penumbra Forge tool keeps input on your device.

  • Browser tools: processing stays in the page unless the tool's disclosure says it makes a network request.
  • Edge tools: the URL, domain, or secret you submit is sent to a Cloudflare Worker operated by Penumbra Forge.
  • Direct network tools: your browser contacts the destination or third-party API named on the tool page; that service receives the request.
  • AI tools: WebGPU mode runs inference in the page after downloading model files. Local-server mode sends prompts, files, passages, or embeddings to the endpoint you configure. API-key mode sends the material needed for the request to the provider URL you configure.
  • Snake multiplayer: room and session-description data pass through Penumbra Forge's signaling worker, the browser contacts Google STUN for NAT discovery, and play then uses a direct WebRTC peer connection. The signaling service, Google, network intermediaries, and the other player may observe network metadata including IP addresses. Solo mode stays in the page.
  • Passkey Inspector live-create: the page asks your authenticator or password manager to create a real credential scoped to penumbraforge.com. Returned registration data is not submitted to an application server, but the authenticator may retain or sync the credential.

The site has no user accounts and does not use advertising cookies. Favorites, recent tools, AI settings, and any API key you choose to save are stored in your browser's local storage. Anyone with access to that browser profile may be able to read them. Tool-invocation fragments such as #in= are not sent in the HTTP request; legacy query-string inputs are sent to the hosting/CDN layer before the tool page runs.

Analytics

We use Cloudflare Web Analytics for aggregate traffic measurements. Penumbra Forge does not use it for advertising or set its own analytics cookies. Cloudflare still processes request and device metadata under its own privacy policy.

Edge Workers and the Remote MCP Endpoint

Site Score, Privacy Scan, and CT Monitor send the submitted URL or domain to a Cloudflare Worker, which makes the requested lookup. The remote MCP endpoint likewise receives the arguments needed for the tool call. Hosting and security infrastructure may create ordinary request metadata or logs; do not send sensitive material merely because a worker normally processes a payload in memory.

One-Time Secret is different: it is not end-to-end encrypted. The secret is sent to a worker and stored in eventually consistent Cloudflare KV. The worker requests deletion after retrieval, but read and delete are not atomic, so concurrent or geographically separated requests may retrieve it more than once before deletion propagates. The worker operator could read the value. Use browser-local Secret Lock first if that is unacceptable.

Open Source Products

Gate, vexes, and mcp-librarian run on your machine and do not require a Penumbra Forge account, but some requested features contact other services:

  • Gate can send a bounded credential value to the relevant provider API when you explicitly enable credential verification.
  • vexes sends package coordinates to OSV, deps.dev, and package registries, can download package archives for deep analysis, and can send sanitized finding data to a model endpoint when AI explanation is explicitly configured.
  • mcp-librarian makes outbound requests when a network or research tool is invoked. The destination receives the requested URL or query.

These projects do not intentionally send telemetry to Penumbra Forge. Consult each project's documentation and configuration before using it with sensitive data.

Third-Party Services

The site uses:

  • GitHub Pages — hosting (subject to GitHub's privacy statement)
  • Cloudflare — CDN, DNS, analytics, and edge-worker hosting (subject to Cloudflare's privacy policy)
  • Google Fonts — font delivery (subject to Google's privacy policy)
  • User-selected services — AI providers, package registries, OSV, deps.dev, Have I Been Pwned, api.ipify.org, target websites, and other destinations contacted only by the features that name them.

Data Retention

Browser-local state remains until you clear site data. One-Time Secret retains its submitted value until TTL expiry or until a post-retrieval KV deletion propagates. User-selected providers and destinations apply their own retention policies. Penumbra Forge does not promise that CDN, hosting, abuse-prevention, or worker infrastructure creates no operational logs.

Children's Privacy

Our services are not directed at children under 13. We do not knowingly collect information from children.
